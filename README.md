# Reynolds Roofing — Vaqueros Sales Competition website concept

A static, mobile-friendly, two-page **educational concept** prepared for the October 15, 2026 Vaqueros Sales Competition role-play. No build tools, npm, backend or paid hosting required.

## What is included

- `index.html`: proposed customer-facing website for Reynolds Roofing (Wayne, NJ)
- `strategy.html`: optional Hibu sales conversation visual aid, with discovery questions, possible digital marketing solutions, and a personalized webinar invitation
- `styles.css`: responsive design
- `script.js`: mobile menu, current year and safe demo form preview
- `assets/favicon.svg`: custom icon

## Upload to GitHub Pages

1. Extract this ZIP file.
2. Open your existing GitHub repository.
3. Select **Add file → Upload files** and drag **all files and the `assets` folder** from inside the extracted folder. `index.html` must be at the top level of your repository.
4. Select **Commit changes**.
5. Go to **Settings → Pages → Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then **Save**.
6. After deployment, visit `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/` for the roofing site and `https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/strategy.html` for the marketing strategy page.

To replace the previous roofing demo, upload these files to the same repository root and commit; the new `index.html`, `styles.css`, `script.js`, and `assets/favicon.svg` can overwrite their existing counterparts. GitHub may require deleting or moving any conflicting files first.

## Suggested role-play usage

The competition scenario is an **initial meeting** with Jordan Reynolds, not a finished marketing contract. **Do not open the website immediately and give a long pitch.** Establish rapport, ask about current lead sources and goals, listen, then optionally use the website as a *short illustrative visual* showing what a modern online customer journey could look like. Use `strategy.html` to connect discovered needs to relevant Hibu One capabilities. Your objective is **to secure a commitment to a personalized Hibu webinar**, not to sell the website outright.

A useful transition: “Based on what you've shared about [their specific concern], would it be helpful if I showed you a brief example of how that could look online?”

A suggested close: “Would you be open to scheduling a personalized Hibu webinar so we can look at your current digital presence and see whether there's a fit?”

## Accuracy and safety notes

- This is an **unofficial, illustrative student concept**. It is **not** Reynolds Roofing's real website and is not endorsed by Reynolds Roofing or Hibu.
- Content about Reynolds Roofing comes from the competition role-play brief. The post-installation service description is qualified; specific terms are not guaranteed.
- The site intentionally has **no invented star ratings, testimonials, customer counts, phone numbers, addresses, awards, certifications, pricing, or performance metrics**.
- The inquiry form **does not transmit or save data**. It displays an on-screen preview only. For real use, add a secure lead form provider and an appropriate privacy policy.
- Photos are remotely loaded from Unsplash and require an internet connection. Replace with company-owned, licensed imagery before commercial deployment. See `PHOTO-CREDITS.md`.
- Google Fonts are also remotely loaded; fallback fonts are included.
- The proposed Hibu One solution areas are illustrative capabilities from the provided training materials, not a quotation or guaranteed result.
